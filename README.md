# Универсальный бот эксперта на GigaChat

Прототип загружает базу знаний в PDF, DOCX, TXT, MD, CSV или JSON и ведёт диалог от имени эксперта. До подключения календаря бот не подтверждает запись и не создаёт фиктивные бронирования.

Для запуска на Render подключите отдельный репозиторий GitHub и создайте Blueprint по `render.yaml`. В переменных окружения укажите `GIGACHAT_AUTH_KEY` и `ADMIN_PASSWORD`. Стандартный scope — `GIGACHAT_API_PERS`, модель — `GigaChat`; при необходимости их можно изменить через `GIGACHAT_SCOPE` и `GIGACHAT_MODEL`.

Панель базы знаний: `/admin`. Тестовый пароль до настройки секрета: `admin123`.

Для записи через Яндекс Календарь добавьте `YANDEX_CALENDAR_LOGIN` (полный адрес Яндекс Почты) и `YANDEX_CALENDAR_APP_PASSWORD` (отдельный пароль приложения с доступом к календарю). Для каждого эксперта отдельно задаются `BOOKING_TITLE`, `BOOKING_DURATION_MINUTES` и `BOOKING_TIMEZONE`. Если в аккаунте несколько календарей, укажите нужный в `YANDEX_CALENDAR_NAME`, иначе используется первый доступный.

Для предварительного теста без реального календаря установите `CALENDAR_MODE=demo`. Записи будут сохраняться в локальной тестовой базе. Для рабочего подключения замените значение на `yandex`.

Перед публикацией нужно дополнительно проверить ответы на нескольких базах и заменить секреты. На бесплатном Render локальный файл базы данных может сбрасываться при перезапуске: для постоянного хранения загружаемых баз потребуется подключить внешнее хранилище. База конкретного эксперта загружается через административную панель.
