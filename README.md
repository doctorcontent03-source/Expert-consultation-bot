# Универсальный бот эксперта на GigaChat

Прототип загружает базу знаний в PDF, DOCX, TXT, MD, CSV или JSON и ведёт диалог от имени эксперта. До подключения календаря бот не подтверждает запись и не создаёт фиктивные бронирования.

Для запуска на Render подключите отдельный репозиторий GitHub и создайте Blueprint по `render.yaml`. В переменных окружения укажите `GIGACHAT_AUTH_KEY` и `ADMIN_PASSWORD`. Стандартный scope — `GIGACHAT_API_PERS`, модель — `GigaChat`; при необходимости их можно изменить через `GIGACHAT_SCOPE` и `GIGACHAT_MODEL`.

Панель базы знаний: `/admin`. Тестовый пароль до настройки секрета: `admin123`.

Перед публикацией нужно дополнительно проверить ответы на нескольких базах, заменить секреты и подключить календарь либо явно оставить режим без записи. На бесплатном Render локальный файл базы данных может сбрасываться при перезапуске: для постоянного хранения загружаемых баз потребуется подключить внешнее хранилище. Демонстрационная база Кирилла автоматически загружается из репозитория при первом запуске.
